=== SRS ===
Software Requirements Specification (SRS) Automatic License Plate Recognition & Vehicle Classification System 1. Introduction 1.1 Purpose Dokumen ini menjelaskan kebutuhan sistem untuk pengembangan Automatic License Plate Recognition (ALPR) yang dapat mendeteksi kendaraan, mendeteksi plat nomor, mengenali karakter plat menggunakan OCR, serta mengidentifikasi body style kendaraan. Sistem akan dikembangkan untuk dapat menerima input berupa gambar dan video, dengan target akhir berupa real-time detection menggunakan kamera. 1.2 Project Objective Tujuan sistem adalah: Mendeteksi kendaraan secara otomatis. Mengidentifikasi jenis kendaraan. Mendeteksi lokasi plat nomor. Membaca nomor plat menggunakan OCR. Mengidentifikasi body style kendaraan. Menampilkan hasil deteksi dan confidence score. Mendukung pemrosesan video dan real-time camera. 2. System Scope 2.1 In Scope Sistem mencakup: Vehicle detection License plate detection Vehicle body style classification OCR license plate recognition Image processing Video processing Real-time detection Model evaluation API integration  2.2 Out of Scope Untuk tahap awal, sistem tidak mencakup: Identifikasi pemilik kendaraan Face recognition Driver recognition Speed detection Traffic violation detection Automatic payment processing Vehicle tracking antar kamera 3. System Overview Secara umum, sistem bekerja dengan alur:   4. Functional Requirements FR   01 — Input Image Sistem harus dapat menerima gambar sebagai input. Format yang didukung: JPG JPEG PNG FR   02 — Vehicle Detection Sistem harus dapat mendeteksi kendaraan pada gambar atau video. Minimal kendaraan yang ditargetkan: Class Priority Car Must Have Motorcycle Must Have Truck Should Have Bus Should Have Output: Vehicle Class Bounding Box Confidence Score FR   03 — License Plate Detection Sistem harus dapat mendeteksi lokasi plat nomor kendaraan. Output: License Plate Bounding Box Confidence Score Contoh: License Plate Confidence: 92% FR   04 — License Plate Cropping Setelah plat terdeteksi, sistem harus melakukan cropping terhadap area plat untuk digunakan pada proses OCR.   FR   05 — OCR Sistem harus dapat membaca karakter dari plat nomor yang telah terdeteksi. Contoh: Input: [image of license plate] Output: B 1234 XYZ Output minimal: License Plate Number OCR Confidence FR   06 — Vehicle Body Style Sistem harus dapat mengidentifikasi body style kendaraan berdasarkan kategori yang tersedia pada dataset/model. Contoh:   SUV ,  MPV ,  Sedan ,  Hatchback ,  Minibus ,  Pickup Catatan:  kategori final akan ditentukan berdasarkan dataset yang digunakan. FR   07 — Result Visualization Sistem harus menampilkan bounding box pada kendaraan dan plat nomor. Contoh: FR   08 — Structured Result Sistem harus menghasilkan informasi kendaraan dalam format terstruktur. Contoh: {     "vehicle_type": "Car",     "body_style": "MPV",     "license_plate": "B 1234 XYZ",     "vehicle_confidence": 0.94,     "plate_confidence": 0.91,     "ocr_confidence": 0.89 } FR   09 — Video Processing Sistem harus dapat melakukan detection pada video dengan memproses frame secara berurutan. Video   ↓ Frame 1 → Detection Frame 2 → Detection Frame 3 → Detection FR   10 — Real-Time Detection Sistem ditargetkan dapat melakukan detection secara real-time menggunakan kamera. Input: Webcam / Camera / CCTV Output: Vehicle License Plate Body Style OCR Result 5. Non-Functional Requirements NFR   01 — Accuracy Model harus memiliki performa yang cukup untuk digunakan pada tahap prototype. Target awal: Vehicle Detection     ≥ 85% License Plate         ≥ 85% OCR                   ≥ 80% Angka ini merupakan  target pengembangan awal , bukan hasil yang sudah dicapai. NFR   02 — Performance Untuk real-time prototype, sistem ditargetkan mencapai minimal:   10 FPS Target dapat ditingkatkan menjadi 15–30 FPS apabila hardware dan model memungkinkan. NFR   03 — Reliability Sistem harus tetap dapat melakukan detection pada kondisi gambar yang berbeda, seperti: Perbedaan ukuran kendaraan Perbedaan posisi kendaraan Kondisi pencahayaan berbeda Kendaraan yang berdekatan Plat nomor dengan ukuran kecil NFR   04 — Usability Hasil detection harus mudah dipahami oleh pengguna melalui: Bounding box Class label Confidence score License plate text 6. AI Model Requirements Sistem akan menggunakan beberapa komponen AI. 6.1 Vehicle Detection Model Contoh: YOLO Target:   Car ,  Motorcycle ,  Truck ,  Bus 6.2 License Plate Detection Model Model khusus untuk:   License Plate 6.3 Body Style Model Model untuk mengenali:   SUV ,  MPV ,  Sedan ,  Hatchback ,  Minibus 6.4 OCR OCR digunakan untuk mengubah gambar plat menjadi teks:   7. Dataset Requirements Dataset harus mencakup data yang sesuai dengan kebutuhan masing-masing model. Vehicle Dataset Minimal:   Car ,  Motorcycle ,  Truck ,  Bus License Plate Dataset Minimal:   License Plate Body Style Dataset Kategori mengikuti dataset yang dipilih. Dataset Quality Dataset harus: Memiliki annotation yang benar Memiliki variasi kondisi kendaraan Tidak memiliki terlalu banyak gambar duplikat Memiliki distribusi class yang cukup Dibagi menjadi training, validation, dan testing 8. Dataset Split Contoh pembagian: 70% → Training 20% → Validation 10% → Testing ( Pembagian dapat disesuaikan berdasarkan ukuran dataset ). 9. Testing Requirements Test Case 1 — Car Input: Image containing car Expected: Vehicle = Car License Plate = Detected Test Case 2 — Motorcycle Input: Image containing motorcycle Expected: Vehicle = Motorcycle License Plate = Detected Test Case 3 — Multiple Vehicles Input: Image containing multiple vehicles Expected: Vehicle 1 → Car Vehicle 2 → Motorcycle Vehicle 3 → Car Test Case 4 — OCR Input: License plate image Expected:   Plate = B 1234 XYZ Test Case 5 — Video Input: Vehicle video Expected: Vehicle detection throughout video Test Case 6 — Real-Time Input: Camera Expected: Real-time vehicle detection + plate detection + OCR 11. Evaluation Metrics Object Detection Precision Recall mAP@50 mAP@50–95 Confidence OCR Character Accuracy Character Error Rate Plate-level Accuracy Real-Time FPS Inference Time Processing Latency 12. === OVERVIEW ===
Sistem   Pengenalan   Kendaraan  dan Plat  Nomor   Otomatis  (ALPR) Latar  Belakang Proses  mengecek   jenis   kendaraan  dan  mencatat  plat  nomor   secara  manual  membutuhkan   waktu  dan  tenaga ,  terutama   jika   jumlah   kendaraan  yang  harus   diperiksa   cukup   banyak . Selain  itu , proses manual juga  bisa   menyebabkan   kesalahan   saat   mengenali   jenis   kendaraan   atau   membaca   nomor  plat. Automatic License Plate Recognition (ALPR)  adalah   teknologi   berbasis  Computer Vision yang  dapat   membantu   mengotomatisasi  proses  tersebut .  Sistem   ini   dapat   mendeteksi   kendaraan ,  mengenali  area plat  nomor ,  membaca   karakter  plat  menggunakan  OCR,  serta   menentukan   tipe   atau  body style  kendaraan . Dalam   proyek   ini ,  saya   akan   membuat   sistem  AI yang  dapat   memproses   gambar  dan video  untuk   mendeteksi   kendaraan ,  mengenali  plat  nomor , dan  menghasilkan   informasi   kendaraan   secara   terstruktur .  Sistem   ini  juga  akan   dikembangkan  agar  dapat   digunakan   secara  real-time  melalui   kamera . Project Objective Tujuan  dari   proyek   ini   adalah   membangun   sistem  Automatic License Plate Recognition (ALPR) yang  dapat   mengenali   kendaraan  dan plat  nomor   secara   otomatis   menggunakan  Computer Vision dan OCR.  Sistem   ini   diharapkan   dapat   memproses   gambar , video,  maupun   kamera   secara  real-time  serta   menghasilkan   informasi   kendaraan  yang  terstruktur .
